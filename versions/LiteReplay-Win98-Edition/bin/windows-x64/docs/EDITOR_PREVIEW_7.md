## 自由摆放性能信息

1. 打开「性能监视器」，勾选要显示的项目。每个启用的项目都可独立摆放，包括 CPU、逻辑核心、GPU、RAM、显存、FPS、磁盘、网络和所选进程。
2. 点击「编辑信息位置」。覆盖层会自动打开，信息卡片暂时以全不透明度显示，并可用鼠标拖动。可将不同卡片放到不同显示器。
3. 点击「完成并保存」。位置写入当前的三套预设之一，卡片恢复预设透明度和鼠标穿透。Ctrl+Shift+F7 同时显示或隐藏所有卡片。
4. 「重置位置」把卡片重新排开。「整块布局」切回可设置行序和列数的合并面板。需要把这些调整记入预设时，点「保存此预设」。

旧预设首次打开时继续使用整块布局。开启自由摆放后，显示项目和字号仍可修改。

## 界面主题

在「设置 → 界面主题」切换。更新后的「经典 98」使用渐变标题条、立体边框和下凹状态栏，显示回放和覆盖层状态。新增「磷光终端」的绿色等宽读数和「霓虹街机」的紫粉配色与圆角按钮。

主题同样应用于桌面覆盖层。 [E6 主题参考](EDITOR_PREVIEW_6.md) · [性能读数与 FPS 采集](EDITOR_PREVIEW_5.md)
