# LiteReplay 2.0 Editor Preview 4

软件由 Yuzi_Lj 制作 · 2026-11-14

## 导出跟随素材，只允许向下调整
- 新工程首次导入视频，分辨率、帧率、目标视频码率默认匹配素材上限；分辨率/帧率列表只列出不高于上限的选项。码率支持小数，输入超过上限时拒绝导出。
- 新版本保存的回放将录制分辨率、帧率、配置的视频码率写入标准 comment 标签。导入时读取那一次录制的参数，不读取用户目前的录制设置。
- 旧录像或外部视频优先读取视频流码率；不存在时使用容器平均码率减去音频码率估算，并在界面标注“含估算码率”。旧版本未保存的录制配置不能从视频精确恢复。
- 多素材工程采用不超过任一素材的分辨率边界、最低帧率及最低码率，保持第一段素材的宽高比例，必要时补边。偶数像素要求可能将奇数尺寸向下取整。
- 支持竖屏、非16:9及29.97/59.94帧等规格。所有导出尺寸不再固定在720p/1080p/1440p。
- CPU MPEG-4兼容编码取消忽略码率的固定质量模式；NVENC和CPU均使用选定目标码率，并设置maxrate/bufsize。码率限制是编码参数上限，不等于短视频文件平均码率或瞬时峰值的逐比特保证；成品还包括音频及封装开销。
- “匹配原视频上限”恢复上限；“重新读取规格”重新探测当前文件并重置为上限。无法取得可靠尺寸/帧率/码率时禁止普通重编码导出，提示重新读取；快速裁剪仍保持源视频码流及其关键帧限制，不使用导出参数。
- 旧LITECUT 1工程可以打开，并在缺少规格时自动后台读取；新工程保存为LITECUT 2，新增源规格字段。旧版软件不能读取新格式，请保留旧工程备份。

规格匹配并不能保证任何播放器都支持输出编码：HEVC或MPEG-4仍取决于播放端解码器。此版不把分辨率/码率不匹配认定为视频打不开的唯一原因。

## 可选系统声音与麦克风设备
进入“即时回放”，在录制音量下方选择：
1. 系统声音：要录制的播放设备，例如USB耳机、扬声器或HDMI输出。
2. 麦克风：实际连接的输入设备。
3. 点击“应用设置”，再启动回放。插拔设备后可点击“刷新设备”。设备选择在停止回放时修改。

默认可继续“跟随Windows默认设备”。选择具体设备后保存其稳定ID，捕获线程打开该设备，不改动Windows默认设备；默认设备变化不会影响显式选择。设备断开后等待原设备恢复并提示错误，不自动换麦。勾选的设备不可用时，启动前要求重选或关闭对应音源。

系统声音采用所选播放设备的WASAPI环回采集，只有送到该播放设备的声音会被录入。应用内选择不依赖更改Windows默认音源，但仍受设备驱动及麦克风隐私权限限制，不绕过权限。

原有系统声/麦克风0–200%录制音量保留；录制中可应用增益，但不会改变已经缓存的声音。

## Windows复测
- 新录一段720p30/6Mbps回放，导入新工程，确认上限为1280×720 /30FPS /6Mbps；输入7Mbps应被拒绝，降低至3Mbps可以导出。
- 导入旧1440p或竖屏视频，核对源规格与下调选项；不同规格拼接不应超过任何一段素材。
- 用两支麦或内置麦+USB麦：停止回放，明确选择USB麦，应用并启动。切换Windows默认麦不应改换当前录制麦；拔出USB麦应提示等待原设备，不能悄悄录入内置麦。
- 系统声音选耳机，确认游戏也输出到该耳机；测试默认设备缺失时手动选择另一有效设备。
- 若出错，提供操作、视频规格及 %LOCALAPPDATA%\LiteReplay\2.0 下相关日志。
