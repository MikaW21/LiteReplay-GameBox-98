# LiteReplay Win98 Edition 1.6 · UI 预览

桌面空白处右键可打开媒体库、控制面板或切换 CRT 扫描线。右键窗口标题栏或任务栏按钮可还原、最小化、最大化或关闭窗口。在媒体库右键素材可播放、进入剪辑或定位文件，右键列表空白处可导入。

软件由 Yuzi_Lj 制作。

先从系统托盘退出正在运行的 LiteReplay，再打开同目录的 `LiteReplay-Win98.exe`。「开始」打开菜单，「开始回放」控制回放录制。

保存的回放会出现在媒体库底部列表。选中视频后可在上方预览，也可以点击「进入视频剪辑」将它送到剪辑器。

打开「控制面板」，可勾选或取消「播放启动动画和音效」。动画播放时，按 Esc 或单击可跳过画面并停止启动声。[Windows 98 启动 WAV 来源](https://www.winhistory.de/more/winstart/winstart_en.htm)

## 1.6 游戏会话与素材

从「开始 → 游戏资料库」进入。在「识别」菜单可将当前所选游戏设为手动匹配，也可结束当前会话并暂停识别。使用「恢复自动识别」即可重新检查已登记的进程。自动识别期间，窗口会标记无效路径和部分进程无法读取的情况。

「会话记录」可以按游戏和开始日期筛选，日期格式为 YYYY-MM-DD。选中会话可查看回放、截图和导出的路径。可以修正已结束会话的游戏归属和时长。意外关闭后，尚未记录结束时间的会话会显示「结束时间待修正」。

媒体库工具栏的「按游戏筛选」包含「全部素材」「未归类」和已登记的游戏。也可以从游戏资料卡打开对应集合。「磁盘空间与素材」支持刷新实际文件大小、查看可用空间、定位文件、手动归档、移除索引或将单个文件移入回收站。移除索引会保留原文件。手动归档只更新索引。选中文件时，面板显示所在目录和卷的可用空间。已有的 1.5 游戏目录素材可按原目录结构识别，历史会话从 1.6 开始记录。

回放和截图按发起保存时的游戏归档。导出优先关联发起时的游戏会话，未识别到游戏时会尝试关联至所有剪辑源素材共同归属的游戏。文件保持在各自保存的位置。切换录制配置会重新积累回放缓存。

控制面板可独立关闭游戏状态提示音和通知。空间提醒默认阈值为 5 GiB，在磁盘空间面板修改。设为 0 关闭空间提醒。提示音是本版本用两个合成音生成的 LiteReplay 自有 WAV。游戏资料、会话和素材关联保存在 %LOCALAPPDATA%\\LiteReplay\\2.0\\GameBox98。
