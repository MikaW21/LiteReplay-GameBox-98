# LiteReplay Retro Edition 1.0

软件由 Yuzi_Lj 制作。基于 LiteReplay Editor7，适用于 Windows 10 和 Windows 11 x64。

## 启动与操作

从系统托盘退出已有 LiteReplay，再运行 `bin/windows-x64/LiteReplay.exe`。同目录内的 DLL、语言文件和工具目录随程序一起使用。

- 在蓝绿色应用内桌面点击像素快捷方式，或从「开始」菜单打开工具。多个内部窗口可以同时打开。
- 拖动蓝色标题条可移动窗口，拖动右下角可调整大小。标题栏按钮分别用于最小化、最大化／还原和关闭。任务栏按钮可以切换、还原或最小化对应窗口。「显示桌面」最小化所有内部窗口。
- 任务栏右侧的 REC 打开回放控制台，HUD 切换自由布局性能覆盖层。时间显示系统本地时间。LiteReplay 也继续使用 Windows 系统托盘菜单。

## 应用窗口

| 窗口 | 操作 |
| --- | --- |
| 回放控制台 | 查看状态、缓存时长和占用，启动回放、保存片段、打开回放配置。 |
| 回放配置与音频 | 调整原有录制、编码、音量、设备和导出位置选项。 |
| 媒体资源管理器 | 搜索、筛选和导入素材。详细列表显示名称、类型、大小和修改日期。可预览、重命名、在资源管理器显示，或送入剪辑。 |
| 视频剪辑 | 使用片段列表、预览、时间标尺以及对齐的视频轨和音频轨。点击或拖动时间轴定位。剪辑继续使用原有顺序片段模型，每段音频随对应视频编辑。 |
| 性能监视器 | 查看系统与进程指标，调整进程调度，编辑桌面覆盖层的指标卡片位置。Ctrl+Shift+F7 可切换覆盖层。 |
| 控制面板 | 切换语言和资源模式，配置截图热键，进入回放、音频和性能设置。 |
| 关于 | 查看版本、开发者、Retro 本地使用统计和成就。右侧是吉祥物预留区。 |

Retro 使用统一的经典外观，沿用 Editor7 的录制配置、素材库索引、剪辑项目及覆盖层预设。Editor7 的主题选择仍由原版本读取。

## 当前测试机的录制兼容性

在搭载 Intel HD Graphics 5500 的 Windows 10 22H2 测试机上，Windows MF 硬件模式初始化时崩溃，NVENC 也无法加载编码接口。若在这台机器上录制，可在回放配置中将编码格式选为 H.264，并将「编码后端」明确设为「CPU 兼容（H.264，较高占用）」。软件模式已通过 720p30 合成帧编码检查，实际桌面录制和音画同步仍待验证。
