# LiteReplay GameBox 98 1.5

桌面空白处右键可打开媒体库、控制面板或切换 CRT 扫描线。右键窗口标题栏或任务栏按钮可还原、最小化、最大化或关闭窗口。在媒体库右键素材可播放、进入剪辑或定位文件，右键列表空白处可导入。

1. 从 Windows 托盘退出正在运行的旧版 LiteReplay。
2. 打开同目录的 `LiteReplay-Win98.exe`。
3. 点击应用内桌面图标或「开始」。在任务栏切换已打开的工具。
4. 点击「开始回放」开始录制。保存回放后，从媒体库预览或送入剪辑器。

## 游戏资料库（1.5）

从开始菜单打开「游戏资料库」，点击「添加游戏」。在「识别程序」选择启动 EXE；如果启动器会拉起另一个游戏进程，可额外登记实际 EXE。基本信息使用启动程序的图标，多个分类用分号分隔。「录制设置」可单独选择回放时长、帧率、分辨率、码率、系统声音设备及麦克风。

资料库左侧按分类或最近游玩筛选，点击右侧列标题切换排序，双击游戏打开属性。点击「启动游戏」运行登记的启动程序。「扫描识别」立即检查进程，后台每三秒自动检查一次。识别依据是完整路径，实际游戏程序优先于启动器。

切换游戏或退出游戏时，正在运行的回放会切换录制配置并重新积累缓存。正在写入的回放会先完成保存。匹配期间保存的文件位于全局保存目录下的 GameBox98/游戏编号，截图在该目录的 Screenshots 中，仍可通过原有媒体库访问。回放数量记录成功保存的次数。未匹配时使用全局设置和保存位置。

资料卡保存在 %LOCALAPPDATA%\LiteReplay\2.0\GameBox98 下。音视频编码器、缓存上限等未在资料卡展示的选项继承全局设置。
