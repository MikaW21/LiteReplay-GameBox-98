# LiteReplay 2.0 Editor Preview 6

软件由 Yuzi_Lj 制作。

从系统托盘退出旧版，然后运行同一交付目录中的 `bin/windows-x64/LiteReplay.exe`。

## 切换界面主题

打开「设置」，在顶部的「界面主题」选择样式。旁边显示当前主题的缩略预览。选择立即生效，下次打开软件会恢复所选主题。

| 主题 | 外观 |
| --- | --- |
| 石墨深色 | 延续 E5 的深灰卡片、圆角和薄荷绿主操作。 |
| 经典 98 | 银灰面板、深蓝标题条、立体按钮、内凹边框和方形控件。 |
| 雾白浅色 | 白色面板、浅蓝灰侧栏和圆角，主要操作使用蓝色。 |
| 碳黑 | 高对比的深灰分层、直角面板和淡蓝主操作。 |

主界面、剪辑和音频面板使用所选主题。已显示的桌面性能覆盖层会同时更新样式，并沿用原来的摆放位置、透明度和显示项目。系统文件选择器等由 Windows 绘制的窗口跟随系统外观。系统原生标题栏着色在支持相应 DWM 属性的 Windows 版本上生效。

## 设计参考

- 经典 98 的配色、立体边框和控件外观参考原版截图。 [Windows 98 截图库](https://guidebookgallery.org/screenshots/win98/)
- 雾白浅色参考 GNOME 的全局浅色外观与圆角分组。 [GNOME UI Styling](https://developer.gnome.org/hig/guidelines/ui-styling.html) · [GNOME Boxed Lists](https://developer.gnome.org/hig/patterns/containers/boxed-lists.html)
- 碳黑参考 IBM Carbon 的中性分层与蓝色操作。 [IBM Carbon 色彩](https://www.carbondesignsystem.com/building-blocks/foundations/color/overview)
