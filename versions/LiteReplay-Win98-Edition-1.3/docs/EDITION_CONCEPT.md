# Win98 Edition 界面方案

## 产品呈现

LiteReplay 是一台围绕即时回放工作的复古桌面系统。用户进入 LiteReplay 桌面，通过功能图标打开工具窗口；桌面和任务栏是持续存在的应用外壳，工具窗口承载具体操作。

## 桌面与任务栏

- 桌面图标：即时回放、媒体库、视频剪辑、性能监视器、设置、关于。
- 「开始」打开开始菜单，用于启动各个工具和退出程序。
- 任务栏独立显示「开始回放」按钮，运行时切换为「停止回放」。
- 任务栏显示打开的窗口、回放状态、缓存/录制计时和通知。状态变化不能只通过颜色表达。
- 窗口支持拖动、缩放、最小化、最大化/还原、关闭及任务栏恢复；默认布局应易于理解，并提供恢复默认布局的方式。

## 视觉方向

- 借鉴 Win98 的灰色控件、凹凸边框、蓝色标题条和像素图标，形成清楚的交互反馈。
- 建立 LiteReplay 自有的桌面壁纸、图标绘制规则和回放状态色，不使用 Windows 标志或直接复刻原版桌面素材。
- 重要层级由版式、大小、间距和状态共同表达；避免所有窗口、按钮和说明都使用同等强度的边框。
- 保留现代显示器下的可读性：支持高 DPI、不同窗口尺寸和键盘操作，像素风不等于小字号。

## 主要工作流

1. 用户点击「开始回放」启动回放录制，任务栏更新录制按钮的状态。
2. 用户可继续使用 LiteReplay 桌面中的媒体库、性能监视器等窗口；窗口之间互不覆盖关键状态。
3. 用户通过即时回放窗口保存片段；系统显示保存进度和完成结果，并提供打开素材的入口。
4. 用户从媒体库选择素材并送入剪辑，剪辑窗口清楚显示当前项目、片段顺序和操作对象。

## 1.2 界面参考

- 媒体库采用黑底播放区、紧贴播放区的进度条和底部素材列表。参考 [Windows Media Player 6.4 实机截图](https://virtualwindows.tistory.com/155)。
- 剪辑器采用顶部工程工具栏、预览与工程素材面板、底部视频和音频时间轴。参考 [Ulead MediaStudio Pro 6.0 手册工作区截图](https://ulead.manymanuals.it/video-software/mediastudio-pro-6-0/users-guide-3303/104)。

## 1.3 启动与任务栏

- 启动画面采用浅蓝云天、LiteReplay 图标和底部循环蓝光。参考 [Windows 98 SE 开机截图](https://www.betaarchive.com/wiki/index.php?title=File:Boot_Screens_Windows_98_SE.png) 和 [调色板循环动画说明](https://mattkc.com/etc/vapor98/)。
- 启动声为 Windows 98 的原版 WAV，由 Ken Kato 创作。控制面板的「播放启动动画和音效」决定下次是否播放。[WAV 来源](https://www.winhistory.de/more/winstart/winstart_en.htm) [声音创作访谈](https://www.20k.org/episodes/tadaitswindows)
- 当任务栏按钮放不下完整名称时，按钮显示居中的图标，悬停提示显示窗口名。内嵌窗口的最小化、最大化和关闭按钮采用标准标题栏图形。

## 设计验收重点

- 首次启动即可分辨桌面图标、开始菜单和回放按钮的用途。
- 回放待命、运行、保存、失败等状态在任务栏和控制窗口中一致。
- 多窗口并用时，窗口切换、缩放、最小化及恢复可预测，不遮挡主要操作。
- 桌面图标数量受控；开始菜单承担搜索和完整功能入口。
- 在常见分辨率与缩放比例下，中文标签、状态和关键控件仍清晰可读。
- 外观能让人联想到 Win98 的桌面交互，同时具备 LiteReplay 自己的图形识别。
