# LiteReplay Win98 Edition 1.1

LiteReplay Win98 Edition 是独立版本线，目标是把 LiteReplay 做成具有自身品牌的伪 Win98 桌面环境。它从 `LiteReplay-Retro-Edition`（Retro Edition 1.0）派生，功能基线与数据兼容要求沿用该版本；视觉与交互改造在本版本线单独进行。

第一轮 UI 改版可运行 `bin/windows-x64/LiteReplay-Win98.exe`。先从系统托盘退出已经运行的 LiteReplay，再打开此版本。

## 核心概念

- LiteReplay 启动后进入完整桌面，而非普通主窗口中的一组页面。
- 桌面图标用于打开即时回放、媒体库、视频剪辑、性能监视器和设置等功能。
- 点击图标后在桌面内打开独立窗口，支持拖动、缩放、最小化、最大化和任务栏切换。
- 左下角「开始」打开菜单，任务栏的「开始回放」独立控制回放录制。
- 媒体库左侧为播放器，右侧可搜索和筛选已保存的素材，也可把选中的视频送进剪辑器。
- 视频剪辑上方并排显示素材列表、预览与导出设置，底部时间轴提供裁剪、分割、定位与缩放。
- 任务栏持续显示录制状态、计时与系统状态；保存片段和错误状态需要清楚反馈。
- 借用 Win98 的窗口边框、任务栏、像素图标和桌面隐喻，不复制 Windows 商标、原版壁纸或系统图标。

## 版本边界

- 当前最新发布仍为 `LiteReplay-Retro-Edition`。
- 开发基线为 Retro Edition 1.0；保留原有回放、素材库、剪辑、性能监视器、设置、截图和兼容性能力。
- Win98 Edition 的 UI、版本号、构建、验证记录和发布说明独立维护。
- 本版本稳定并经确认前，不改变 Retro Edition 的发布状态或源码。
